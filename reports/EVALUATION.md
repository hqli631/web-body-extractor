## Trafilatura外部基线对照

项目固定使用 [adbar/trafilatura](https://github.com/adbar/trafilatura) 2.3.1 作为独立传统正文提取基线。对照覆盖九篇历史网页和六篇 Python 官方 Sphinx 文档页，共15页：

| 页面组 | 页面数 | 对照结果 |
|---|---:|---|
| 新浪新闻 | 3 | 字符 5-gram F1 为0.972至0.986；基线常额外带入推荐、直播或滚动播报组件 |
| 中新网新闻 | 3 | F1 为0.886至0.914；基线带入“国内新闻精选”或“社会新闻精选”时间列表，我们保留部分图说 |
| Paul Graham博客 | 3 | F1 为0.989至1.000；质量很高，但基线常把整篇合并成1至7个文本段，顺序指标受分块方式影响 |
| Python教程适配页 | 3 | F1 为0.989至0.998；代码块和段落高度一致 |
| Python文档留出页 | 3 | F1 为0.985、1.000和0.149；最后一页是目录型页面，差异有明确结构原因 |

正文指标只比较两部分结果的正文块，不把本项目已单独分类的作者、责任编辑、来源和发布时间混入F1；这些页面信息在页面信息表中单独展示，也不作为正文块差异。总结：15/15页运行成功，15/15标题一致，平均字符 5-gram F1 为0.9169，平均块级匹配 F1 为0.8952；3页标记为需人工核查。pydoc_library_index的F1为0.1494，基线只保留5段导语，我们的规则保留39个正文块，其中包括 `div.toctree-wrapper` 下的标准库目录。该页不是普通文章，保留目录更符合“网页可见主要内容”，因此不应为了迎合基线而删掉目录。对照也发现Trafilatura并非人工标注：chinanews_01和chinanews_03的基线独有文本包含相关新闻时间列表；Trafilatura参照结果中出现的责任编辑、记者署名或来源，如果已由本项目在页面信息中保留，就从块级差异列表排除，并不表示信息缺失。

完整方法和数据见 [Trafilatura基线说明](../docs/TRAFILATURA_BASELINE.md) 与 [对照报告](trafilatura_comparison.html)。逐页原始基线结果保存在 `output/trafilatura_reference/`。

### 块级近似匹配修正

早期块级结果显示，Trafilatura 行首的 Markdown 符号 `|`、空白差异或单个标点差异，会被完全相等比较误报成“只在基线中”和“只在我们的结果中”；Python 教程中代码块被合并或拆分也会造成同类假差异。本轮没有修改正文抽取规则，只修正了对照协议和评判指标。

- 单个文本块与对面块集合的去空白字符覆盖率达到 `0.95`，或长度相近时局部字符相似度达到 `0.95` 时，按近似匹配计算，不进入未匹配差异列表。
- 块级匹配按每侧独立计算，允许一段基线对应多段规则结果，或反向对应，避免把合理分块直接算成遗漏。
- 近似匹配只计数，不在报告中展开原文；未匹配列表只保留真正没有对应内容的文本块。
- 块级对齐只比较正文；已分类页面信息和 Trafilatura 中带来源、作者、编辑、发布时间等标签的页面信息行都从差异列表排除；全文 5-gram F1 保留不变，作为正文覆盖证据；块级匹配精确率、召回率和 F1 作为结构诊断证据，不单独触发人工核查。

修正后平均块级匹配精确率为 `0.9224`、召回率为 `0.9202`、F1 为 `0.8952`；未匹配块从完全相等比较时的基线侧880个、规则侧134个降到基线侧28个、规则侧47个。Paul Graham 的 `|` 差异、单个标点和 Python 代码块合并差异已转为近似匹配，元数据差异已从对照差异点中排除，不再出现在未匹配列表。`pydoc_library_index` 的目录仍保留为规则侧未匹配块，因为这是页面类型与抽取口径的真实差异，不是格式噪声。

## 这些结果能够说明什么

本项目已形成“按布局定位→正文与杂质区分→结构化保存→报告展示→历史回归→外部基线差异诊断”的可运行链路，可以作为项目一的入门交付。

9/9表示功能与历史回归通过率，不是正文语义准确率。原文对应不证明无遗漏；二十三项测试综合了抽取控制、真实页面分类断言和基线协议，也不代表真实网页分布。Trafilatura是外部参照，不是人工标注；它的加入提高了可复核性，但不产生完整率、纯净度或跨站准确率。

当前支持四类静态布局及规则覆盖的杂质模式，并为其已适配页面提供页面信息分类。图片像素、JavaScript后加载正文、分页未处理；博客日期和注释可能保留在正文。源HTML未附带完整CSS和图片资源，本地视觉可能不同。具体边界见 [范围说明](../docs/SCOPE.md)。
