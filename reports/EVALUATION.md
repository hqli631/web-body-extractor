## Trafilatura外部基线对照

项目固定使用 [adbar/trafilatura](https://github.com/adbar/trafilatura) 2.3.1 作为独立传统正文提取基线。对照覆盖九篇历史网页和六篇 Python 官方 Sphinx 文档页，共15页：

| 页面组 | 页面数 | 对照结果 |
|---|---:|---|
| 新浪新闻 | 3 | 字符 5-gram F1 为0.972至0.986；基线常额外带入推荐、直播或滚动播报组件 |
| 中新网新闻 | 3 | F1 为0.886至0.914；基线带入“国内新闻精选”或“社会新闻精选”时间列表，我们保留部分图说 |
| Paul Graham博客 | 3 | F1 为0.989至1.000；质量很高，但基线常把整篇合并成1至7个文本段，顺序指标受分块方式影响 |
| Python教程适配页 | 3 | F1 为0.989至0.998；代码块和段落高度一致 |
| Python文档留出页 | 3 | F1 为0.985、1.000和0.149；最后一页是目录型页面，差异有明确结构原因 |

总结：15/15页运行成功，15/15标题一致，平均字符 5-gram F1 为0.9169；3页标记为需人工核查。pydoc_library_index的F1为0.1494，基线只保留5段导语，我们的规则保留39个正文块，其中包括 `div.toctree-wrapper` 下的标准库目录。该页不是普通文章，保留目录更符合“网页可见主要内容”，因此不应为了迎合基线而删掉目录。对照也发现Trafilatura并非金标：chinanews_01和chinanews_03的基线独有文本包含相关新闻时间列表。

完整方法和数据见 [Trafilatura基线说明](../docs/TRAFILATURA_BASELINE.md) 与 [对照报告](trafilatura_comparison.html)。逐页原始基线结果保存在 `output/trafilatura_reference/`。

## 这些结果能够说明什么

本项目已形成“按布局定位→正文与杂质区分→结构化保存→报告展示→历史回归”的可运行链路，可以作为项目一的入门交付。

9/9表示功能与历史回归通过率，不是正文语义准确率。原文对应不证明无遗漏；十四项测试综合了合成控制和基线协议，也不代表真实网页分布。Trafilatura是外部参照，不是人工金标；它的加入提高了可复核性，但不产生完整率、纯净度或跨站准确率。

当前支持四类静态布局及规则覆盖的杂质模式。图片像素、JavaScript后加载正文、分页未处理；博客日期和注释可能保留。源HTML未附带完整CSS和图片资源，本地视觉可能不同。具体边界见 [范围说明](../docs/SCOPE.md)。
