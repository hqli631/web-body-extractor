# 项目一范围与证据说明

本目录从已有学习项目整理而来，仅包含 Python+lxml+XPath 规则抽取、代表性网页、评测报告和必要回归验证，不包含 LoRA、模型权重、API 凭据、自动代码生成 Agent 或强化学习。

## 支持范围

- 新浪新闻正文布局：主标题和 artibody 正文容器。
- 中新网新闻正文布局：content_left_title 与 left_zw 容器。
- Paul Graham 传统博客布局：旧式 table/td/font 与 br 文本分段。
- Python 官方 Sphinx 文档布局：语义 role=main 容器，覆盖教程页和部分索引页。

这几类是已适配布局，不等于所有新浪、所有中新网、所有博客或所有 Python 文档页面。动态站点、登录后内容、跨页正文、图片内文字、视频语音及反爬验证不在本版范围。

## 样例与评测边界

当前样例来自原项目已查看、调试或评测过的本地网页，以及独立保存的 Python 官方文档页面。主回归页全部应视为历史曝光的演示/回归材料；Python 文档清单中的三页标记为留出页，但它们仍不是完整人工标注。样例来源、哈希与具体清单查看 samples/manifest.json 和 samples/pydoc_manifest.json。不能把已看过的开发页面重新贴成“全新未见测试”标签。

报告可证明本机这次运行的执行状态、输出结构、原文对应与已确认回归结果；Trafilatura对照可证明两个抽取器的字符级差异和差异位置，但不产生没有独立人工标注支持的正文准确率。规则抽取没有 API 调用或模型参数更新。

## Trafilatura外部基线

项目使用固定版本 Trafilatura 生成独立参照结果，并把每页原始JSON、字符5-gram指标、块级匹配指标和未匹配文本写入对照报告。块级对齐阈值为 `0.95`：一个文本块的去空白字符至少有 95% 能从对面文本块集合中覆盖，或长度相近时局部字符相似度至少达到 95%，就按近似匹配计算；完全相等另计。字符 5-gram F1 和块级差异都只统计正文，已分类页面信息单独展示，Trafilatura 结果中以文章来源、作者、编辑或发布时间等标签开头的页面信息行也从差异列表排除。由于两边分块粒度不同，一段基线可能覆盖我们的多个块，我们的多个块也可能共同覆盖一段基线。

近似匹配只表示“这不属于需要报告的块级差异”，不表示两边内容都正确，也不等于人工标注。未匹配列表才是需要回看原始HTML的候选差异：未匹配的基线块是基线中存在而规则结果没有找到对应内容的块；未匹配的规则块是规则结果中存在而基线没有覆盖的块。全文字符 5-gram F1 和块级匹配率是两种诊断证据，不能互相替代。

Trafilatura可能带入推荐列表、责任编辑、导航或其他页面组件，也可能漏掉目录、列表和代码结构，因此它是差异检测工具，不是绝对正确答案。

出现低分或需核查标记时，应同时检查原始HTML、页面类型或模板意图、两边独有片段和基线设置。不能为了让指标变高而自动删除我们结果中的内容，也不能把基线结果直接覆盖成参考答案。

## 内容保留原则

主要叙述、结论、真实访谈提问、承载信息的图说和表格应保留。作者、责任编辑、来源、发布时间和制作署名属于有用页面信息，应按字段单独分类，不与正文块混在一起；广告组件、导航、评论入口或互动引导应排除。含有链接不自动等于广告；“中新社记者：……”这样的采访问题不是独立作者行。

定位正文容器可整体避开页面外的导航、侧栏或评论，但不意味着每个排除区域都会单独产生标签。容器内部仍需按结构和语义边界清理。

页面信息只有在规则能给出稳定选择器、文字确实来自该节点且不会误伤正文时才进入结构化输出。无法可靠定位的日期、注释或相似署名宁可保留在正文并记录为边界，也不应通过宽泛关键词误删。

## 已知限制

- 仅有静态 HTML 无法读到图片像素或 JavaScript 后加载的文字；相关完整性保持未知。
- 块级匹配指标受分块粒度影响，尤其是一段长文本与多段短文对应时；“近似匹配”可能合计两侧块数，只用于诊断，不单独作为正文准确率。
- 源网页的 CSS、图片资源可能不完整，本地打开的视觉效果不保证与原站一致。抽取不通过重建页面判断位置。
- 博客中的日期、注释等可能随正文保留；br 分段是布局启发式。
- 文本会规范化空白，不能承诺代码缩进、诗歌或复杂排版完全保真。
- 博客段落可能引用整个正文容器的 XPath：证明文字出现在容器内，不代表拥有逐段唯一 DOM 节点。
- 规则对容器和样式有假设。同站改版或不同栏目可能需要另建规则，不应静默返回看似合理的空结果。
